# 07 · 用户全流程使用说明（不用本地模型也能用）

> 这份说明写给**第一次使用、并且不打算折腾本地模型**的人：
> 你不需要显卡，不需要装 Ollama，不需要懂命令行。
> 只要有一台能上网的 Windows 电脑，加一个云端模型的 API Key，就能从"拍张错题照片"走到"打印一份错题本"。
>
> 软件版本：v1.2.0　　适用系统：Windows 10 / 11

---

## 0. 先选一条路线（3 分钟读完，能省你一小时）

软件支持三种运行方式，**第一次用请直接选「云端优先」**：

| | ① 云端优先（**推荐给大多数用户**） | ② 本地优先 + 云端兜底 | ③ 纯本地 |
| --- | --- | --- | --- |
| 需要显卡吗 | **不需要** | 需要（能跑 4B 视觉模型，约 4–6 GB 显存） | 需要 |
| 需要装额外软件吗 | **不需要** | 需要装 Ollama + 下模型（约 3 GB） | 需要 |
| 需要 API Key 吗 | **需要**（付费，通常几分钱一张卷） | 需要（但只在"看不准"时才用） | 不需要 |
| 图片会离开你的电脑吗 | **会**（发给云端服务商） | 大部分时候不会，兜底时会 | 不会 |
| 识别速度 | 看网速，通常几秒一张 | 本地较快，兜底会慢 | 看电脑 |
| 适合谁 | 普通学生、家长、老师 | 有游戏显卡、在意隐私的人 | 断网环境、极度在意隐私 |

> 这份说明**只讲路线 ①**。如果你有显卡、想走路线 ②/③，看
> [`01-安装部署教程.md`](01-安装部署教程.md) 与 [`05-模型与云端接口配置教程.md`](05-模型与云端接口配置教程.md)。

**一句话原理**：软件把你的错题照片交给云端的大模型"看"，模型读出题干、你的作答、对错，
再自动分类归档、生成错题分析。所有题目、报告、原图**都存在你自己电脑上**，只有识别那一刻图片会离开本机。

---

## 1. 开始前，准备两样东西

### 1.1 一台电脑

- Windows 10 / 11，能正常上网。
- 屏幕 1366×768 以上（软件窗口最小约 1120×720）。
- **不需要显卡。** 这一点很重要：软件第一次启动时会在左下角提示「本地模型服务未就绪」，
  **选了云端优先就可以完全忽略它** —— 那只是说"本机没装小模型"，而你的识别走云端，用不到它。

### 1.2 一个云端模型的 API Key（唯一需要花钱的地方）

API Key 是一串以 `sk-` 开头的密码，从模型服务商的控制台申请。要点：

- 必须选**支持"看图片"的视觉模型**（软件要靠它读你的照片）。纯文本模型（如 `deepseek-chat`）不行。
- 按用量计费，一次识别一张卷通常几分钱到一毛钱；错题分析每道题再花一点。
- 建议先充最小额度试，跑顺了再充。

| 服务商 | Base URL（填这个） | 支持图片的模型名（填这个） | 申请入口 |
| --- | --- | --- | --- |
| 阿里通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max` 或 `qwen-vl-plus` | 阿里云百炼控制台 → API-KEY |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v` 或 `glm-4v-plus` | 智谱开放平台 → API Keys |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | platform.openai.com → API keys |
| 自建/中转网关（OneAPI 等） | `http://你的服务器:3000/v1` | 网关里配置好的渠道模型名 | 网关后台生成"令牌" |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | ⚠️ **纯文本，看不了图片**，只能用于错题分析，不能用于识别 |

> 表格来自 [`05-模型与云端接口配置教程.md`](05-模型与云端接口配置教程.md) 第 6 章（更全、含 8 家服务与价格提示）。
> 服务商随时可能改名/改价，以官方控制台为准。

## 2. 第一次启动

1. 解压软件到一个**不含中文和空格的路径**（例如 `D:\exerarchive`）。
2. 双击 **`启动.bat`**（想看排错信息就双击 `启动-控制台.bat`，会多留一个黑窗口显示日志）。
   第一次启动会略慢，稍等几秒会弹出主窗口。
3. 你会看到：
   - 左边一列按钮：导入整理 / 我的题库 / 错题分析 / 学习概览 / 搜索题目 / 图片优化 / 归档目录 / 运行日志；
   - 中间一张大卡片写着「**从一张习题照片开始**」，下面一个蓝色按钮「＋ 导入习题图片」；
   - **底部左下角**可能显示「本地模型服务未就绪（可在设置里检查）」→ **忽略它**，做完第 3 章就好了；
   - 底部右下角显示当前会用哪个模型（配好云端后会显示「云端模型 xxx」）。

你的所有数据都在软件目录下的 **`data`** 文件夹里（题库、原图、归档、日志）。**拷贝这个文件夹就等于搬家**，删掉它就是彻底清空。

## 3. 配好云端模型（关键一步，约 5 分钟）

### 3.1 打开设置

主窗口右上角 **「设置」** → 切到 **「云端模型」** 标签页。

### 3.2 填 4 个字段

| 界面上的字段 | 填什么 | 例子 |
| --- | --- | --- |
| **名称** | 随便起个名字 | `通义千问视觉` |
| **Base URL** | 第 1.2 节表格里对应的一行 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| **模型名** | 表格里"支持图片"的那个模型 | `qwen-vl-max` |
| **API Key** | 你申请到的那串 `sk-...` | `sk-xxxxxxxx` |

**别忘了勾上「该模型支持图片」** —— 这是本说明里最容易漏、后果最严重的一个勾选框：
不勾的话软件**不会把图片发给云端**（只发文字），而云端拿不到图片就完全没法识别，
你会看到"识别出 0 道题"。

同时确认这一页顶部的 **「启用云端增强（填好 API Key 后勾选）」** 已勾上。

### 3.3 点两个按钮验证

- 点 **「测试连接」**：应显示连接成功。
- 点 **「获取模型列表」**：能从服务商拉回模型名清单（用来核对"模型名"是否写对）。

### 3.4 选「云端优先」并保存

1. 切到 **「运行模式」** 标签页；
2. 选 **「云端优先」**（第一项是"纯本地"、第二项是"本地优先+云端兜底"，都不适合没装本地模型的你）；
3. 点右下角 **「保存」**。

> ⚠️ 保存按钮在**窗口右下角固定位置**（窗口再小也看得见）。如果你在旧版本里找不到它，升级到 v1.2.0 即可。
> 保存后，底部状态栏右下角应该变成 **「云端模型 qwen-vl-max」** 这类字样 —— 看到它就说明配置生效了。

### 3.5 隐私设置（顺手看一眼）

「隐私与存储」标签页里：

- **「允许把图片传给云端模型」**：云端优先时必须开着（关掉就等于云端收不到图，识别不了）。
- 「题库正文加密存储」：建议保持开启。
- 数据默认全部留在本机；云端服务商那边是否留存图片，取决于该服务商的隐私政策。

## 4. 日常使用：十步走完一遍

### 第 1 步 · 导入照片

**在哪**：「导入整理」页 → 工具栏 **「＋ 导入图片」**（一次可选多张），或 **「导入文件夹」**（整批导入）。

**拍照小贴士**：光线均匀、卷面放平、四角都在画面内、字迹清晰。一张卷拍一张，比一张拍半页更准。

导入后左边「图片队列」会列出文件名，状态是「待识别」，右侧能看到整页预览。

### 第 2 步 · （可选）先优化图片

**在哪**：选中队列里的图 → 点 **「优化图片」**（或左栏「图片优化」）。

- **一键优化**：自动纠偏、提亮、锐化 —— 手机拍的歪照片建议先点这个；
- **框选裁剪/去水印**：拖着框出区域；
- **旋转纠偏**：左转/右转 90°，或填微调角度点「应用」；
- 调完务必点**右下角「保存处理结果」**（这个按钮固定在工具区底部，滚动工具列表也不会跑掉）。

> 不做这一步也能识别：软件默认会在识别前自动纠偏+提亮（设置 → 运行模式 → 「导入后自动纠偏/提亮/锐化」）。

### 第 3 步 · 开始识别

**在哪**：工具栏 **「开始识别 →」**。

- 识别期间页头会持续显示进度：`第 1/2 张 · u6_math_linalg_eigen.jpg · 云端识别 · 已用 3 秒`
  —— 第几张、文件名、当前阶段、已用秒数都在这儿，不会"看起来卡死"；
- 若勾了「识别出错题后自动生成分析报告」，识别完还会自动跑一段 `生成错题分析 1/1`；
- 批次结束后，底部状态栏右下角会写 **「本次识别：cloud:qwen-vl-max」**，明确告诉你这次是谁干的活；
- 等不及可以点「停止」。

**会花多少钱**：按图片张数与模型计费。想省钱可以把「设置 → 运行模式 → 单图最多题目数」调小、
把「设置 → 本地模型 → **送模型最长边**」调小（默认 1600，调到 1200 更省 token，字小可能吃亏）。

### 第 4 步 · 核对识别结果（**最重要的一步**）

**在哪**：「我的题库」→ 选中一道题 → 右侧「题目详情」。

- 默认是**排版预览**：题干、选项、我的答案、参考答案、知识点都按课本样式排好，能直接读；
- 公式（积分、矩阵、分数、求和）会自动排版成图片样式；
- 要改字就点 **「修改识别内容」** → 变成可编辑的输入框（这时才会显示公式源码）→ 改完点 **「保存修改」**；
- 想先看看改得对不对，点 **「查看排版预览」**，**此时不会写进数据库**，只有点「保存修改」才真正保存；
- 保存后页头会提示「修改已保存，可继续核对下一道题。」

> 为什么必须核对：模型偶尔会把 `3` 看成 `8`、把 `tan 2x` 看成 `2x`。
> 题干错了，后面的错题分析也会跟着错。

### 第 5 步 · 看错题分析

**在哪**：左栏 **「错题分析」** → 选一道错题。

- 页面顶部一行写着 **「报告来源：云端模型生成（你的模型名）」**，能确认这份报告是谁生成的；
- 报告分几段：错题还原 / 错误原因分析 / 正确解法 / 避错技巧 / 变式练习；
- 右侧「原题图片」是你的原始照片，可以**双击放大**对照自己的笔迹；
- 想重新生成：点「生成 / 更新分析」；想用云端强力模型做深度版：点「云端深度分析」。

### 第 6 步 · 按知识点找同类错题

**在哪**：「我的题库」→ 左上的三个下拉框（状态 / 学科 / **知识点**）。

知识点下拉框会带题数，例如 `不定积分（4）`。选中后列表只剩这一类题，
适合"考前把同一类错题连着刷一遍"。

### 第 7 步 · 搜索

**在哪**：左栏 **「搜索题目」**。题干、答案、知识点、报告全文都能搜到。

### 第 8 步 · 看学习概览

**在哪**：左栏 **「学习概览」**。图片数、题目数、错题数、正确数、未做数、报告数一目了然。
配合「错题分析」页的**知识点薄弱清单**导出，能看出该补哪一块。

### 第 9 步 · 导出复习材料

**在哪**：工具栏 **「导出 ↓」** → 选一种：

| 选项 | 用途 |
| --- | --- |
| 选中题目… | 只导出你在题库里勾中的几道 |
| **个人错题本…** | 最常用：把错题整理成一份可打印的册子 |
| 知识点薄弱清单… | 按知识点统计你的薄弱项，用于定复习计划 |
| 错题汇总… | 全部错题的清单式汇总 |
| 全部题目… | 连正确题一起导出（备份/交给老师看） |

格式支持 **Word（.docx）/ PDF / Markdown / 纯文本 / 网页**。给老师看选 Word 或 PDF；
自己复习选 Markdown 也行。导出成功后，页头会提示「已导出：xxx.docx（1.6 MB）」，**文件名就在提示里**。

### 第 10 步 · 备份与换电脑

- 备份：右上「更多 ⋯」→ **「备份数据…」** → 得到一个 zip；
- 换电脑：把整个软件目录（含 `data`）拷过去即可，或者用「从备份恢复…」；
- 导出全部数据（JSON）：同样在「更多 ⋯」里，适合交给别的程序处理。

## 5. 遇到问题怎么办（按现象查）

### 5.1 「识别出 0 道题 / 本地模型服务不可用」

如果你选的是**云端优先**，看到"本地模型服务不可用"这句通常是**误导**，真正原因多半是云端没配好：

| 检查项 | 怎么查 |
| --- | --- |
| 「云端增强」开关开了吗 | 工具栏右侧按钮应显示「☁ 云端增强：开」；开着才会走云端 |
| API Key 填了吗 | 设置 → 云端模型 → API Key 是否为空 |
| 「该模型支持图片」勾了吗 | **没勾的话云端收不到图片**，这一项最容易被忽略 |
| 「运行模式」选对了吗 | 应为「云端优先」 |
| Base URL / 模型名写对了吗 | 点「测试连接」「获取模型列表」验证 |

> v1.2.0 起，遇到这种情况软件会直接在**运行日志**里写明：
> 「『云端优先』已选中，但云端当前不可用（没填 API Key，或没勾『启用云端增强』）……请到「设置 → 云端模型」填好 Key」。
> 看到这句就照做。

### 5.2 「本地模型服务未就绪」一直提示

云端优先模式下**可以无视**。这条提示只是说本机没装小模型。
想让提示消失：设置 → 本地模型 → 取消勾选「启动软件时自动拉起本地模型服务」。

### 5.3 报错对照表

| 现象 | 常见原因 | 怎么办 |
| --- | --- | --- |
| `HTTP 401` / `403` | API Key 错、过期、或没开通该模型 | 重新复制 Key；确认控制台里该模型已开通 |
| `HTTP 404` | Base URL 或模型名写错（把 `/v1` 写了两遍也会 404） | 照第 1.2 节表格逐字抄 |
| `HTTP 429` | 触发限流/欠费 | 等一会儿，或充值、降低并发与图片清晰度 |
| 请求超时 | 图片太大 / 网络慢 / 模型太慢 | 调小「送模型最长边」；换更快的小视觉模型；稍后重试 |
| 识别结果缺题、串题 | 一张图里题目太多 | 调小「单图最多题目数」，或一张卷拆成两张拍 |
| 识别出来是乱码/空 | 图片太糊、反光、太暗 | 用「图片优化 → 一键优化」，或重拍 |
| 公式显示成 `\int` 之类 | 旧版本缺陷（v1.2.0 已修） | 升级到 v1.2.0 |
| 设置改了像没生效 | 旧版本缺陷（v1.2.0 已修） | 升级到 v1.2.0；保存后核对底部状态栏右侧的模型名是否变了 |
| 找不到「保存」按钮 | 旧版本缺陷（v1.2.0 已修） | 升级；新版本保存按钮固定在窗口右下角 |

### 5.4 想省钱

1. 用**便宜的小视觉模型**（如 `qwen-vl-plus`、`gpt-4o-mini`）做识别；
2. 「设置 → 运行模式」里关掉「错题分析使用云端深度版」「变式练习题由云端生成」——分析改用本地规则版（免费）；
3. 调小「送模型最长边」（1600 → 1200）与「单图最多题目数」；
4. 先用「图片优化」把整页裁成单题，一张图只送一道题；
5. 校对过的题不必重复识别。

### 5.5 断网了会怎样

云端优先模式下断网 = 识别会失败（会提示云端不可用）。此时可选：

- 恢复网络后重新识别；
- 或在「设置 → 运行模式」切到「本地优先」/「纯本地」—— 但这需要你装过本地模型（见第 0 节路线 ②/③）。

## 7. 小词典

| 词 | 意思 |
| --- | --- |
| **API Key** | 云端服务商给你的密码（`sk-` 开头），软件用它证明"是你在调用" |
| **Base URL** | 服务商的接口地址，必须照抄，写错会 404 |
| **视觉模型 / 支持图片** | 能"看图"的模型。识别必须用它；纯文本模型只能读文字 |
| **识别 / OCR** | 把照片里的字读成文本 |
| **归档** | 软件按 学科/学段/题型/状态 自动把题目分文件夹保存，并写一份 .md 文字稿 |
| **token** | 云端计费单位，图片与文字都折算成 token |
| **本地模型** | 装在自己电脑上的小模型，不联网也能识别；不想折腾就忽略它 |

## 8. 想用本地模型（可选，附）

只有当你**有独立显卡（≥4–6 GB 显存）**、且在意隐私或想省 API 费用时才需要：

1. 装 Ollama：`05-模型与云端接口配置教程.md` 第 2 章（路线 A），或全程图形界面的 LM Studio（路线 B）；
2. 拉模型：`ollama pull qwen3-vl:4b`（约 3 GB）；
3. 软件里：设置 → 本地模型 → 点「刷新模型列表」选中 `qwen3-vl:4b` → 「测试连接」→ 保存；
4. 设置 → 运行模式 → 选「本地优先 + 云端兜底」；
5. 验证：设置 → 本地模型 → 「重新加载模型」可让模型按当前空闲显存重新规划，
   底部状态栏会显示实际占用的显存比例（装不满显存会明显变慢）。

常见坑：**软件只认「设置 → 本地模型 → 服务地址」里的地址**，不读 `OLLAMA_HOST` 环境变量；
如果本机 Ollama 监听的不是 `11434`，两边必须改成一致，否则会一直报「本地模型服务不可用」。

## 9. 五分钟上手（懒人版）

1. 申请一个视觉模型的 API Key（第 1.2 节表格）；
2. 设置 → 云端模型：填 名称/Base URL/模型名/API Key → **勾「该模型支持图片」** → 测试连接 → 保存；
3. 设置 → 运行模式：选 **「云端优先」** → 保存；
4. 工具栏「＋ 导入图片」选你的错题照片 → 「开始识别 →」；
5. 「我的题库」里核对题干 → 「错题分析」看错因 → 「导出 ↓ → 个人错题本」打印出来。

> 全程不需要显卡、不需要命令行。底部若提示「本地模型服务未就绪」，忽略即可。
