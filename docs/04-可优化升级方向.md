# 可优化升级方向

本文档面向「打算继续把这个工具做下去」的人：按**投入产出比**从高到低排列，
每条都写清楚「做什么 / 怎么做 / 需要动哪些文件 / 预期收益 / 风险」。

> 说明：当前版本（v1.0.0）已经跑通完整闭环 —— 导入 → 预处理 → 本地识别 → 云端兜底 →
> 分类归档 → 错题分析 → 搜索统计 → 多格式导出，并且零第三方依赖、133 项单元测试通过、
> 本地模型在 6 张样张上题数与对错状态 14/14 全对。下面的方向都是在此基础上的增量改进。

---

## 一、识别准确率（收益最大，优先做）

### 1. 题目自动切分（一张图多题拆成单题图片）★推荐
- **现状**：一张卷子识别出多道题，但归档时共用同一张原图。
- **升级**：让模型在识别时同时返回每题在图片中的**归一化边界框**（`bbox: [x1,y1,x2,y2]`，
  0~1 之间），然后 `imageops.Image.crop()` 按框裁剪出单题小图，归档目录里每道题一张图，
  复习时不用在一整页里找。
- **改动**：`prompts.py`（输出格式加 bbox）、`pipeline.py`（归一化 bbox）、
  `archive.py`（多写一个 `{uid}_题目.jpg`）；纯加法，风险低。
- **收益**：错题本可直接打印成「一题一卡」，复习效率明显提升。

### 2. 多模态模型的两阶段识别（粗读 + 精读）
- **现状**：一次调用直接输出全部题目的结构化结果，一页题多时容易漏题。
- **升级**：第一遍只让模型「数出有几道题、每题的题号与题型」（输出极短、快）；
  第二遍按题逐个调用（图片可按上一版 bbox 裁小，速度反而更快）。也可做成
  「先整页识别 → 发现某题置信度低 → 只对该题的裁剪图重新识别」。
- **改动**：`pipeline.py` 增加 `strategy: single | two_pass` 配置；`config.py` 加开关。
- **收益**：一页 6 题以上的卷子漏题率显著下降。

### 3. 识别结果自校验（用规则挑明显错误）
- **现状**：完全信任模型输出。
- **升级**：加一层轻量校验，例如：选择题的 `student_answer` 不在 A/B/C/D 里、
  题干长度 < 6 个字、`correct_answer` 与 `student_answer` 的格式明显不同类（一个是字母一个是长句）、
  同一张图的 `subject` 出现多个值 —— 命中任一条就标记 `need_review`，在界面上高亮，
  并可自动触发云端复核。
- **改动**：新增 `exerarchive/validators.py`，在 `pipeline.py` 收尾处调用；`store.py` 加 `need_review` 字段。
- **收益**：把「看起来成功其实错了」的结果挡在归档之前。

### 4. 数学公式转 LaTeX / 结构化输出
- **现状**：公式按模型读出的近似文本保存（如 `∫₀¹ x² dx`）。
- **升级**：提示词要求公式用 `$...$` 的 LaTeX 表示，导出 Word/HTML 时用 MathJax（HTML）
  或 OMML（Word）渲染；PDF 走浏览器打印时公式会自动排版好。
- **改动**：`prompts.py`、`exporter.py`（HTML 引入 MathJax CDN 或在离线时退化显示）。
- **收益**：错题本里的公式终于「像书上那样」；注意离线场景需要把 MathJax 一起打包。

### 5. 手写体专项模型 / 二次识别
- **现状**：手写体靠通用视觉模型（qwen3-vl 4B）硬读，潦草时准确率下降。
- **升级**：对**学生作答区域**单独走一次「手写 OCR」模型（如 PaddleOCR 的手写模型、
  Qwen3-VL 更大尺寸），题干仍用本地小模型；或对低置信度手写区域做图像增强
  （二值化 + 笔画加粗）后再识别。
- **改动**：`vlm.py` 增加第二个本地模型配置 `local.handwriting_model`；`pipeline.py` 增加分支。
- **收益**：手写答案识别率提升最直接的一招。

## 二、做题与复习闭环（从「整理」走向「提分」）

### 6. 错题重做与间隔复习（SRS）
- **升级**：给每道错题加「掌握度」与「下次复习时间」，用艾宾浩斯间隔（1/2/4/7/15/30 天）
  生成每日复习清单；界面上做「今日待复习」页签，支持「遮住答案自测 → 标记掌握/仍不会」。
- **改动**：`store.py` 加 `review` 表（`question_id, due_at, stage, result`）；
  `ui/app.py` 加页签；`exporter.py` 加「今日复习单」导出。
- **收益**：把静态错题本变成每天会催你的复习工具。

### 7. 变式题自动组卷 / 专项训练
- **升级**：把 `reports.variants` 汇总成「按知识点组卷」，或直接调用云端模型按薄弱知识点
  生成一套 10 题小卷（含答案），导出一份可打印的 PDF。
- **改动**：`analysis.py` 加 `build_paper(knowledge_points, count)`；`exporter.py` 复用现有 PDF 路径。
- **收益**：从「看错题」升级到「练同类题」。

### 8. 家长/老师视图
- **升级**：生成一份只含统计与薄弱点的周报（不包含具体题目），
  或反向：生成「本周错题小卷」让孩子重做。用同一套数据导出两种视角。
- **改动**：`exporter.py` 加 `export_weekly_report(scope)`。

## 三、输入与流程体验

### 9. 手机拍照直传（同一 WiFi 下浏览器上传）
- **升级**：内置一个极简 HTTP 服务（标准库 `http.server`），手机浏览器打开
  `http://电脑IP:8765` 就能拍照上传，照片自动进入待识别队列。
- **改动**：新增 `exerarchive/mobile_server.py`，主界面加一个开关按钮。
- **风险**：需要提示用户仅在同一局域网开启，并加一个随机访问口令。

### 10. 拖拽导入 / 剪贴板粘贴 / 截图即识别
- **现状**：只能通过「导入图片/导入文件夹」按钮。
- **升级**：Windows 下用 `tkinter` 的 `DND_FILES`（需 `tkdnd`，或退化为监听 `WM_DROPFILES`）
  实现拖拽；加「从剪贴板导入」按钮（把截图直接识别）。
- **改动**：`ui/app.py` 加绑定；剪贴板可用现有 `gdiplus` 从 CF_DIB 取像素。

### 11. 批量导入的增量与去重
- **现状**：导入时按文件名复制，重复导入会产生重复记录。
- **升级**：已经在 `images` 表里存了 `sha1`，导入前先查重（`store.find_image_by_sha1`），
  命中则提示「这张已经识别过，是否覆盖/跳过」；支持「只导入新增文件」。
- **改动**：`ui/app.py::_do_import` 十几行代码即可。

### 12. 试卷整体解析（含答案页匹配）
- **升级**：一份卷子常有「题目页 + 答案页」，可让模型识别页脚/标题判断角色，
  把答案页的答案自动匹配到前面的题目上（按题号），减少「参考答案为空」的情况。
- **改动**：`pipeline.py` 增加 `role: questions|answers|mixed` 判定与匹配逻辑。

## 四、性能与工程

### 13. 并行识别
- **现状**：串行处理（`run.max_concurrency` 预留了配置但未启用）。
- **升级**：显存足够时（≥8G）用 2 个线程同时调用本地服务（Ollama 支持并发请求，
  但要注意 `num_ctx` 与显存占用），或按图片分组批量提交。
- **改动**：`pipeline.py::process_batch` 用 `concurrent.futures.ThreadPoolExecutor`。
- **收益**：批量导入时总耗时近乎减半；**风险**：显存不足会直接 OOM，需做成可选开关。

### 14. 识别缓存
- **升级**：以图片 sha1 + 提示词版本为键缓存识别结果，重复导入/重跑不重复调用模型。
- **改动**：`store.py` 加 `cache` 表或写 `data/cache/*.json`。

### 15. 打包成免安装 exe
- **升级**：用 PyInstaller（`--onefile --noconsole`）打包，用户连 Python 都不用装；
  注意要处理 `tkinter` 与 `data/` 相对路径（`paths.app_root()` 在打包后需要改用
  `sys.executable` 所在目录）。
- **改动**：新增 `build/pack.spec` 与 `打包exe.bat`；`paths.py` 加一行 `getattr(sys, 'frozen', False)` 判断。
- **收益**：真正意义上的「小白一键用」。

### 16. 数据库迁移与版本管理
- **升级**：给 `SCHEMA` 加 `user_version`，写一个轻量迁移器（v1→v2 自动 `ALTER TABLE`），
  避免以后加字段时用户数据要重建。
- **改动**：`store.py::_migrate()`。

### 17. 日志与可观测性
- **升级**：把每次识别的「耗时 / tokens / 引擎 / 是否兜底 / 质量分」写进一张 `metrics` 表，
  界面上给一条「识别质量趋势」曲线，方便判断是不是该换模型或调参数。
- **改动**：`store.py` 加表，`ui/app.py` 统计页加图。

## 五、隐私与安全

### 18. 用户口令加密（当前只有机器密钥）
- **现状**：`crypto.Cipher` 已支持「主密钥 + 用户口令」，但界面上没暴露。
- **升级**：设置里加「设置访问口令」，用口令加密数据库正文；
  并实现「导出加密备份（带口令）」与「换机后用口令恢复」。
- **注意**：口令丢失即无法解密，必须在界面上给出强提示并提供「导出明文备份」的选项。

### 19. 云端数据脱敏
- **升级**：上传前可选择自动抹掉姓名/学号/班级等字段（正则 + 关键词表），
  只把题目内容发给云端。
- **改动**：`pipeline.py` 增加 `privacy.redact` 钩子。

### 20. 审计与一键清除云端记录
- **升级**：记录每次云端调用的时间/模型/token 数（本地留痕），
  并提供「清除本地留痕」按钮，让用户能自证「什么数据、什么时候发过」。

## 六、界面与无障碍

### 21. 深色主题与新布局
- **现状**：固定的浅色主题（`ui/widgets.py::COLORS`）。
- **升级**：把配色抽成主题字典，增加深色主题与字号缩放（`ui.font_size` 已存在，
  把各处硬编码的字体大小都改成读它即可）。

### 22. 键盘流与快捷键
- **升级**：`Ctrl+O` 导入、`Enter` 开始识别、`←/→` 切换图片、`1/2/3` 标记对/错/空白、
  `Ctrl+S` 保存修改 —— 批改几十道题时效率差别很大。

### 23. 错题卡片视图（卡片式翻卡复习）
- **升级**：用 Canvas 画「正面题干 / 反面答案+报告」的翻卡界面，配合第 6 项的 SRS 使用。

### 24. 公式排版继续增强
- **现状**：`exerarchive/mathdraw.py` 已能排上下标、分式、根号（含次数）、**Σ/∏/lim 的上下限
  （居中排在符号正上/正下方，符号本身放大 1.3 倍）**、积分上下限（按中文课本习惯保留在右侧）、
  矩阵行列式、希腊字母与关系符；还实现了 LaTeX 的两条排版规则：函数名后的细空格
  （`\sin x` → "sin x"，不是 "sinx"）与 **script style 不加运算符间距**
  （Σ 下面写 `k=0` 而不是 `k = 0`）。
  未实现 `\left(...\right)` 自动伸缩括号、`align`/`split` 多行对齐、
  `\overbrace`、化学式 `\ce{}`、自定义宏 —— 遇到不认识的命令会降级成可读文本。
- **升级 A（小）**：把 `Renderer.layout` 里的 `\left`/`\right` 接上「按内容高度选括号字号」的
  现成逻辑（`_fit_size` + `glyph_ink` 已经具备，只差接线）。
- **升级 B（中）**：`align`/`split` 环境按 `&` 对齐点排成多行表格（可复用矩阵的行列布局）。
- **升级 C（大）**：改为输出**矢量**（EMF 或 SVG）而不是位图，任意缩放都清晰；
  Windows 可用 GDI 的 EMF 记录（`CreateEnhMetaFile`），HTML 侧直接内嵌 SVG 更小更清晰。
- **升级 D（可选）**：内置一份精简 MathJax（约 1MB）供 HTML 导出使用，
  这样导出的 HTML 公式是可选中的文字而非图片（代价：包体变大、需要额外文件）。
- **自查工具**：`python -m exerarchive.mathdraw verify/math-preview.png` 一键出对照图。

## 七、模型侧的长期优化

### 24. 本地微调（LoRA）
- **思路**：把用户自己修正过的识别结果（界面上手改后保存的）当作训练数据，
  用 LoRA 微调一个小视觉模型（如 Qwen2.5-VL-3B），让它更适应本校/本人的试卷版式与手写。
- **门槛**：需要 GPU 与训练环境，属于进阶玩法；建议先积累 500+ 条「模型输出 vs 人工修正」样本。
- **改动**：`store.py` 已保存人工修正后的结果，只需再加一个「导出训练集（JSONL）」按钮。

### 25. 提示词版本化与 A/B 测试
- **升级**：给 `prompts.py` 的模板加版本号，写入每条识别记录；
  提供一个「用两组提示词跑同一批样张并对比准确率」的脚本（可复用 `tools/verify_recognition.py`）。

| 阶段 | 做什么 | 预计收益 |
| --- | --- | --- |
| 第一步 | 第 1、11、14 条（题目自动切分、导入去重、识别缓存） | 立竿见影的体验提升，改动集中、风险低 |

| 第四步 | 第 15、21、22 条（打包 exe、主题、快捷键） | 让更多人真的用得起来 |
| 长期 | 第 5、24 条（手写专项、LoRA 微调） | 针对个人手写与本校卷型的极致优化 |
