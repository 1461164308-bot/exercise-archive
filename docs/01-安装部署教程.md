# 01 · 安装部署教程

> 面向对象：**完全不懂代码的学生和家长**。每一步都写清「点哪里、看到什么、出问题怎么办」。
> 照着做，30~60 分钟能让软件在本机跑起来，而且**全程离线**完成识别。

配套文档：`docs/02-使用教程.md`（怎么用）、`docs/03-常见问题排查.md`（报错怎么办）、
`docs/05-模型与云端接口配置教程.md`（可选：接云端强力模型）。

## 0. 一分钟了解这个软件

**AI本地错题习题归档整理工具**（英文名 `exerarchive`，v1.0.0）装在自己电脑上：
把做过的习题册、试卷、作业**拍照或扫描**，它自动识别每道题的题干、你的作答、对错，
然后整理成错题本，并给出错因分析和知识点归纳。核心特点是**本地 + 云端混合**：

| 能力 | 谁来做 | 要不要联网 | 要不要花钱 |
| --- | --- | --- | --- |
| 习题识别（看图→文字）、自动切题、判对错 | 本机小模型 | ❌ 不用 | ❌ 免费 |
| 错题基础分析、自动归档、导出错题本 / Word / PDF | 本机 | ❌ 不用 | ❌ 免费 |
| 云端深度分析（可选的加分项） | 云端大模型 | ✅ 需要 | 💰 用你自己的 API Key |

软件有三种运行模式（「设置 → 运行模式」里切换）：

| 模式 | 界面名字 | 适合谁 |
| --- | --- | --- |
| `hybrid`（默认） | 本地优先 + 云端兜底 | 大部分人。识别不清的自动请云端复核；**没填 Key 会自动退化成纯本地，不报错** |
| `local_only` | 纯本地（完全离线） | 在意隐私、网络不稳 |
| `cloud_first` | 云端优先 | 已有 Key，想要最准的结果 |

一句话：**拍照 → 自动识别 → 自动判对错 → 错题进错题本 → 一键导出 Word/PDF 打印复习。**

## 1. 准备工作：看看你的电脑行不行

| 项目 | 最低要求 | 推荐配置 |
| --- | --- | --- |
| 内存 | 8 GB | 16 GB 及以上 |
| 显卡 / 显存 | 无独显也能跑（纯 CPU 很慢）；显存 4 GB 可跑 4B 量化模型 | NVIDIA 显卡，显存 ≥ 6 GB（本机实测为 RTX 3070 8G） |
| 磁盘空间 | 10 GB 可用 | 20 GB 以上（模型约 3.3 GB + 图片 + 归档） |
| 拍照设备 | 手机拍完传电脑即可，不强制扫描仪 | 拍平一点，识别更准 |

**操作系统**：Windows 10/11（64 位）✅ 首选，全部功能可用；macOS（Intel / Apple 芯片）✅ 可用，
仅中文渲染自检会跳过（不影响使用）；Linux ⚠️ 本教程不覆盖。

**这个软件要装什么？** 只需要 Python，其它全是 Python 自带的：

| 组件 | 必需性 | 说明 |
| --- | --- | --- |
| Python 3.8+ | ✅ 必需 | 自带 tkinter 图形界面库 |
| Ollama 或 LM Studio | ✅ 必需（二选一） | 提供本地视觉模型服务 |
| 本地视觉模型 | ✅ 必需 | 推荐 `qwen3-vl:4b` |
| Pillow | ⭕ 可选 | 提高图片兼容性（`pip install pillow`）；不装也能解码常见格式 |
| Edge / Chrome | ⭕ 可选 | 有它导出 PDF 更清晰；没有会改用内置渲染器（图片版 PDF，体积略大） |
| Office / WPS | ❌ 不需要 | Word 导出是内置的 |

> 💡 支持的图片格式：jpg / jpeg / png / bmp / gif / tif / tiff / webp。

> ⚠️ **常见坑：以为没独显就用不了。** 不对，纯 CPU 也能跑，只是慢很多——一页三道题可能要 30 秒~2
> 分钟。先按本文装好试一下，觉得慢再换小模型（见 4.3 节）。

## 2. 安装 Python（必须做，约 5 分钟）

### 2.1 Windows 10 / 11

1. 浏览器打开官方地址 **<https://www.python.org/downloads/>**，点黄色大按钮
   **Download Python 3.x.x**（**不要**去第三方网站下"绿色版 Python"，容易带捆绑软件）。
2. 双击安装包，**先做一件最重要的事**：

   > ⚠️ **本教程第一大坑：安装向导第一屏底部的「Add python.exe to PATH」必须勾上！**
   > 不勾的话，后面双击 `启动.bat` 会提示「没有找到 Python」。
   > 已经装完才发现没勾？重新运行安装包选 **Modify / Repair**，或卸载后重装一遍。

3. 勾好后点 **Install Now**，等进度条走完点 **Close**；然后按 `Win + R` → 输入 `cmd` → 回车，
   在黑窗口里执行 `python --version`，看到 `Python 3.12.10` 这类输出即成功。

> ⚠️ **常见坑：输入 `python` 后弹出微软应用商店。** 说明 PATH 没配好。重新运行安装包 →
> **Modify** → 确保勾选 `Add Python to PATH`，完成后重新验证。

### 2.2 macOS

1. 打开 **<https://www.python.org/downloads/>** 下载 macOS `.pkg` 安装包。
   macOS 自带的 Python 往往偏旧，**建议自己装 3.10 以上**。
2. 双击 `.pkg`，一路「继续 → 同意 → 安装」，输入开机密码。
3. 打开「启动台 → 其它 → 终端」，执行 `python3 --version`，看到 `Python 3.12.x` 即成功。

> ⚠️ **常见坑：macOS 上的命令是 `python3` 而不是 `python`。** 本文后面所有命令，macOS 用户
> 把 `python` 换成 `python3`、`py` 换成 `python3` 即可。

### 2.3 验证 tkinter（Python 自带的界面库，正常无需安装）

Windows 在 `cmd` 里执行 `python -c "import tkinter; print('tkinter OK')"`；
macOS 在「终端」里执行 `python3 -c "import tkinter; print('tkinter OK')"`。
输出 `tkinter OK` 就对了。报错时：Windows 重装 Python 并勾选 `tcl/tk and IDLE`；
macOS 用 python.org 官方安装包重装（Homebrew 版有时缺 tk）。

## 3. 获取软件：把文件夹放到正确的位置

### 3.1 放哪里？

| 位置 | 推荐 | 原因 |
| --- | --- | --- |
| `D:\exercise-archive` | ✅ 强烈推荐 | 英文路径、有写权限、不占系统盘 |
| `C:\exercise-archive` | ✅ 可以 | 英文路径、有写权限 |
| `C:\Users\你的名字\Documents\exercise-archive` | ✅ 可以 | 有写权限 |
| `C:\Program Files\exercise-archive` | ❌ 不要 | 需要管理员权限才能写文件，软件会启动失败 |
| `C:\桌面\错题工具`（含中文的路径） | ⚠️ 不推荐 | 部分模型服务程序对非 ASCII 路径处理不佳 |

### 3.2 为什么一定要「英文路径 + 非 Program Files + 有写权限」？

因为本软件是**绿色便携**设计：所有数据（数据库、图片、日志、加密密钥）都写在
**软件自己目录下的 `data\` 里**，不写注册表、不写系统目录。好处有三：
① **拷贝即迁移**——整个文件夹拷到 U 盘或新电脑，数据原样跟着走；
② **删除即卸载**——删掉文件夹就等于清空所有痕迹；
③ **互不干扰**——多份拷贝放不同位置，各用各的数据。

代价是软件必须能往自己的 `data\` 目录**写文件**。`C:\Program Files` 默认只允许管理员写入，
所以放那里必然失败；非 ASCII 路径的风险来自外部程序（Ollama 等）读取图片时的编码处理。
环境自检里专门有一项「数据目录可写」查这个，失败时长这样：

```text
❌ 数据目录可写        [WinError 5] 拒绝访问
   ↳ 建议：把软件放到有写权限的目录（不要放 C:\Program Files）
```

> ⚠️ **常见坑：把软件解压到「下载」文件夹直接用。** 能用，但「下载」容易被清理工具一键清空，
> 连着你的题库一起删掉，请至少挪到 `D:\` 下的固定目录。

### 3.3 想换数据位置（可选）

默认数据目录 = 软件目录下的 `data\`。想让数据放别处，用环境变量 `EXER_HOME` 指定，
设好之后再用 `python -m exerarchive`（macOS 用 `python3 -m exerarchive`）启动即可：

```powershell
# Windows cmd（临时生效）
set EXER_HOME=D:\exer-data
# Windows PowerShell（临时生效）
$env:EXER_HOME = "D:\exer-data"
# macOS（临时生效）
export EXER_HOME="$HOME/exer-data"
```

> 💡 归档根目录是**另一件事**：在「设置 → 归档 → 归档根目录」里单独改，留空表示用 `data\归档`。

> 💡 `EXER_HOME` 只影响**数据**（`data\` 里的数据库、原图、归档、日志、密钥）。
> 程序代码、`tools\`、`docs\`、`samples\` 仍然跟着软件目录走——所以设了 `EXER_HOME`
> 之后，`启动.bat`、`环境自检.bat` 这些还是从软件目录双击，不需要搬。
> 想把数据挪到 U 盘/移动硬盘，建议设成**永久**环境变量（Windows：`系统属性 → 高级 → 环境变量`）。

> ⚠️ 数据一旦放到别处，`data\master.key` 也跟着走了。**迁移时整目录一起拷**；
> 只拷 `archive.db` 会导致加密正文解不开（界面上表现为题干/报告空白）。

## 4. 部署本地视觉模型（二选一）

本地识别需要「一个常驻的模型服务 + 一个视觉模型」。两条路线**任选一条**，都装也行（软件里可随时切换）。
先看对比，再选一条照着做：

| 对比项 | 路线 A：Ollama | 路线 B：LM Studio |
| --- | --- | --- |
| 操作方式 | 命令行（其实只要几条命令） | 全图形界面 |
| 服务默认端口 | **11434** | **1234** |
| 软件里「服务类型」 | `ollama` | `lmstudio` |
| 自动拉起服务 | ✅ 稳定（`ollama serve`） | ⚠️ 依赖 `lms` 命令，失败时手动开 |
| 推荐模型 | `qwen3-vl:4b` | `Qwen3-VL-4B-Instruct-GGUF` |

### 4.1 路线 A：Ollama

**第 1 步：下载安装。** 打开 <https://ollama.com/download>，点 **Download for Windows**
（macOS 点 macOS 版）。双击安装包一路下一步，默认装到 `C:\Program Files\Ollama\`，
并会**开机自动在后台运行**。打开 `cmd` 执行 `ollama --version`，看到版本号（本机实测 `0.34.0`）即成功。

**第 2 步：下载视觉模型。** 在 `cmd`（macOS 用「终端」）里执行 `ollama pull qwen3-vl:4b`。
约 3.3 GB，视网速几分钟到几十分钟，进度条一直滚属正常。下完执行 `ollama list` 确认列表里有
`qwen3-vl:4b`。

**第 3 步：认识这个模型。** 模型名 `qwen3-vl:4b`，参数量 4.4B（44 亿参数），量化 Q4_K_M，
磁盘占用约 3.3 GB，上下文长度 262144（25 万 token 级别，超长），能力是视觉（看图）+ 文本。

**本机实测性能（RTX 3070 8G）**：生成速度约 **70~90 tokens/s**；单张图（一页 3 道题）识别约
**6~8 秒**；预处理为自动对比度拉伸 + 缩放至最长边约 1600px（约 1131×1600）；
识别置信度通常在 0.85~0.95。换台电脑快慢会有差异，可用 `tools\modelprobe.py` 自己实测。

**第 4 步：软件会自动找到 Ollama（通常不用手填）。** 探测顺序：
① 软件目录 / 上一级 / 上上级目录下的 `ollama\ollama.exe` → ② 这三个目录下的 `ollama.exe`
→ ③ `C:\Program Files\Ollama\ollama.exe` → ④ `%LOCALAPPDATA%\Programs\Ollama\ollama.exe`
→ ⑤ 系统 PATH 里的 `ollama`。
模型目录的探测顺序：软件目录/上级/上上级里的 `ollama-models` 或 `models`
（要求含 `manifests` 或 `blobs` 子目录）→ 然后 `~\.ollama\models`。探测到的路径会自动写进配置文件。

**本机实际部署情况（可作为示例参考）**：程序 `C:\deepseek\ollama\ollama.exe`（版本 0.34.0）、
模型目录 `C:\deepseek\ollama-models`、数据目录 `C:\deepseek\ollama-home`、使用的模型 `qwen3-vl:4b`。
对应的 `data\config.json` 的 `local` 块：

```json
"local": {
  "kind": "ollama",
  "base_url": "http://127.0.0.1:11434",
  "model": "qwen3-vl:4b",
  "auto_start": true,
  "server_exe": "C:\\deepseek\\ollama\\ollama.exe",
  "models_dir": "C:\\deepseek\\ollama-models",
  "home_dir": "C:\\deepseek\\ollama-home",
  "timeout": 300,
  "num_ctx": 8192,
  "max_image_side": 1600,
  "jpeg_quality": 88,
  "keep_alive": "10m",
  "disable_thinking": true
}
```

> ⚠️ **常见坑：Ollama 装在别处，软件找不到。** 打开「设置 → 本地模型」，
> 在**服务程序路径**点「浏览」选中 `ollama.exe`，**模型目录**填模型所在目录（如 `D:\ollama-models`），
> **数据目录**填 `.ollama` 所在位置，然后点「保存」。

**第 5 步：软件会自动拉起本地服务。** 这是本软件的贴心设计——**你不需要手动开 Ollama**：
启动软件后自动检测服务在不在跑，没跑就自动执行 `ollama serve` 拉起来（Windows 下静默无窗口），
之后每秒轮询一次直到就绪，最多等 60 秒；就绪后状态栏显示「本地模型服务已就绪」。
想关掉：**设置 → 本地模型 → 取消勾选「启动软件时自动拉起本地模型服务（推荐）」**。

> ⚠️ **常见坑：一直卡在「等待本地模型服务超时」。** 处理顺序：
> ① 看 `data\logs\app.log` 最后几十行；② 在 `cmd` 里手动执行 `ollama serve` 看报错；
> ③ 确认 11434 端口没被别的程序占用；④ 在设置里手动指定服务程序路径后重试。

**第 6 步（可选）：用探测工具自查。**

```bat
python tools\modelprobe.py                     :: 列出服务状态与已安装模型（含是否支持识图）
python tools\modelprobe.py --start             :: 先自动拉起本地服务再列
python tools\modelprobe.py --vision            :: 造测试图实测识图能力与速度
python tools\modelprobe.py --set qwen3-vl:4b   :: 把该模型写进配置
```

> 💡 `--vision` 会现场造一张含中英文和数学符号的测试图，输出类似
> `— 最长边 1600px：成功　6.8s　281 tokens　41 tok/s`，并打印模型实际读到的内容和第 1 题的对错判定。

### 4.2 路线 B：LM Studio

**第 1 步：下载安装。** 打开 <https://lmstudio.ai/>，点 **Download**，下载 Windows 版
（macOS 用户下载 Apple 芯片版本），双击安装并打开。

**第 2 步：搜索并下载模型。** 点左侧**放大镜图标（Search / Discover）**，搜索框输入
**`Qwen3-VL-4B-Instruct-GGUF`** 回车，选一个 GGUF 版本（Q4 量化版，文件大小 **3 GB 左右**）点
**Download** 等进度条走完，最后点左侧 **My Models（文件夹图标）** 确认模型已在本地。

> ⚠️ **常见坑：下了个不带 `VL` 的纯文本模型。** 比如只搜 `Qwen3-4B`，那是纯文字模型，
> **看不了图片**。名字里必须有 **VL**（Vision-Language，视觉语言）。Ollama 路线同样要认准 `qwen3-vl`。

**第 3 步：启动 Local Server。** 点左侧 **Developer** 标签（图标像 `< >`）；把顶部
**Status: Stopped** 下拉改成 **Start Server**；状态变成 **Running** 即成功（**默认端口 1234**）；
CORS / Serve on Local Network 保持默认，本机使用不需要改。

> ⚠️ **常见坑：端口不是 1234。** 如果你在 LM Studio 里改过端口，后面「服务地址」也要跟着改，
> 两者必须一致。

**第 4 步：在软件里切成 LM Studio。** 双击「启动.bat」→ 右上角 **设置** → **本地模型** 标签页：
把**服务类型**从 `ollama` 改成 **`lmstudio`**，**服务地址**填 `http://127.0.0.1:1234`，
**模型名称**点「刷新模型列表」后从下拉框里选中你下载的 Qwen3-VL 模型。
填好点 **测试连接**，看到「本地模型正常 ✅」就成功，再点 **保存**。
（服务类型下拉框共三项：`ollama`=本机 Ollama、`lmstudio`=LM Studio、
`openai_compatible`=任意其它 OpenAI 兼容的本地服务。选 `lmstudio` 时走 OpenAI 兼容的
`/v1/chat/completions` 接口。）

**第 5 步：关于自动启动。** 服务类型为 `lmstudio` 时，软件会尝试调用 LM Studio 官方命令行
`lms server start`。没装 `lms` 命令时自动启动会失败——这时**手动打开 LM Studio 并点
Start Server 即可**，软件界面上也会这么提示。

### 4.3 显存不够怎么办？

| 方案 | 怎么做 | 效果 |
| --- | --- | --- |
| ① 换更小的量化模型 | 拉取 2B~4B 的 VL 量化模型 | 显存需求明显下降，准确率略降 |
| ② 同一模型换更低精度 | 拉取 Q4 以下（更小）的量化 tag | 显存下降，速度上升 |
| ③ 调小送模型的图片尺寸 | 设置 → 本地模型 → **送模型最长边**：`1600` → `1100` | 显存和耗时都下降；太小会看不清小字 |
| ④ 调低压缩画质 | 设置 → 本地模型 → **压缩画质**：`88` → `80` | 体积略降，速度影响很小 |
| ⑤ 降低上下文长度 | 设置 → 本地模型 → 上下文（`num_ctx`，默认 8192）调小 | 显存占用下降 |
| ⑥ 一次只处理一张图 | 保持 `max_concurrency = 1`，**不要调大** | 显存小的机器必须保持 1 |
| ⑦ 关闭思考链 | 勾选「关闭思考链」（默认已勾选） | 识别更快，输出更短 |
| ⑧ 退回纯 CPU | 什么都不用设，Ollama 会自动用 CPU | **能跑，但慢很多**（一页可能 30 秒~2 分钟） |

> ⚠️ **常见坑：以为「本地识别」需要一直联网。** 不需要。模型下载完成后，`local_only` 模式下
> **断网也能识别**；只有「云端兜底」相关功能才需要网络。

> ⚠️ **常见坑：把「送模型最长边」调到 600 以下，结果小字号题目识别不出来。** 这个值不是越小
> 越好，推荐区间 **1100~1600**；调小后质量明显变差，说明是显存问题而非分辨率问题，
> 请回到方案 ① / ②。

## 5. 首次启动与环境自检

### 5.1 两个启动方式

| 文件 | 用途 | 特点 |
| --- | --- | --- |
| **`启动.bat`** | 日常使用 | **不显示黑窗口**，双击直接弹出软件界面 |
| **`启动-控制台.bat`** | 排错时用 | **保留黑窗口**，能看到日志和红字报错，关掉窗口即退出软件 |

`启动.bat` 的查找顺序是 `py` 启动器 → `pythonw` → `python`，找到哪个用哪个。三个都没有时会提示
「没有找到 Python，请先安装 Python 3.8 以上版本（安装时勾选 Add Python to PATH）」——
看到这句就回到第 2 章重装 Python（记得勾 PATH）。

macOS 没有 `.bat`，用「终端」进目录后执行：

```bash
cd /Users/你的用户名/exercise-archive
python3 -m exerarchive
```

   「本地模型服务已就绪」（首次可能要等十几秒）；

### 5.3 环境自检：17~20 项检查怎么看

**三种跑法**：①（推荐）双击 **`环境自检.bat`**，弹出黑窗口跑检查，跑完停在结果页；
② 软件里点右上角 **`环境自检`** 按钮，结果打印在 `运行日志` 标签页；
③ 命令行：`python tools\selfcheck.py`（人类可读报告）／加 `--json` 输出 JSON／加
`--out 诊断.json` 直接写 UTF-8 文件（最省心，不受控制台编码影响）／加 `--no-model` 跳过模型实测、跑得更快。

报告开头长这样：

```text
============================================================================
　AI本地错题习题归档整理工具　环境自检　v1.0.0
============================================================================
✅ Python 版本                3.12.10（win32）
✅ 图形界面库 tkinter          可用（自带，无需安装）
...
----------------------------------------------------------------------------
结论：18 项检查，失败 0 项，警告 0 项
一切正常，可以开始使用了 🎉
```

三种状态标记：✅ 正常不用管；⚠️ 核心功能可用但体验打折，建议按「↳ 建议」处理；
❌ 该功能现在用不了，**必须**按「↳ 建议」处理。下面是 7 组检查项的逐项说明。

**① 基础环境**：`Python 版本`（应显示如 `3.12.10（win32）`，低于 3.8 判 ❌，去 python.org 装新版）、
`图形界面库 tkinter`（应显示「可用（自带，无需安装）」，报错就重装 Python 并勾选 `tcl/tk and IDLE`）、
`磁盘剩余空间`（低于 2 GB 判 ⚠️，清理磁盘）。

**② 数据与加密**：`数据目录可写`（应显示 `data` 目录完整路径；❌ 说明没写权限，
把软件挪出 `C:\Program Files`）、`加密模块自检`（应显示 `ChaCha20/HMAC 通过 RFC 8439 官方测试向量`；
❌ 时检查是否有杀毒软件改写文件）、`数据库`（应显示 `可读写：...\data\archive.db`；
❌ 时检查 `data` 权限，或删除 `data\archive.db` 让它重建，**会丢失题库**）。

> 💡 「加密自检」是什么：软件默认把题干、作答、错题报告**加密后**存进数据库
> （配置项 `privacy.encrypt_db`，默认开启），用 ChaCha20 + HMAC，密钥是本机的 `data\master.key`。
> 也就是**别人拷走 `archive.db` 也读不出内容**。自检跑的是 RFC 8439 官方测试向量，
> 通过就说明加密算法在这台机器上算得对。

**③ 图像处理能力**：`图像解码后端`（`Pillow` 或 `Windows GDI+` 最好；若显示
`纯Python（PNG/BMP）` 判 ⚠️，此时**只能读 PNG/BMP**、JPG 读不了，装 Pillow 解决）、
`GDI+ 绘图`（应显示「可用（导出 PDF/示例图需要）」）、`中文字体渲染`
（应显示 `SimHei 渲染出 1234 个笔画像素`；⚠️ 说明中文可能显示成方块，装黑体/雅黑或在设置里换字体）。
安装 Pillow（可选但推荐）：Windows 用 `python -m pip install pillow`，macOS 用
`python3 -m pip install pillow`。

**④ 显卡占用（识别变慢先看这里）**：`显卡（NVIDIA）`一项会显示显卡型号、GPU 利用率、
显存已用/总量与温度，例如 `NVIDIA GeForce RTX 3070：占用 88%，显存 4901/8192 MB（空闲 3.2 GB），温度 70°C`。
占用率高于 60% 或空闲显存低于 2.5 GB 会判 ⚠️——**打游戏、剪视频、开视频会议时识别会明显变慢甚至超时**，
因为 4.4B 的视觉模型装不进显存就会退回 CPU 推理。处理办法见
[`03-常见问题排查.md`](03-常见问题排查.md) 的「附录二：识别突然变慢 / 卡住不动」。

**⑤ 本地模型与视觉实测（最关键的一组）**：`本地模型服务`（应显示
`运行中（ollama @ http://127.0.0.1:11434）`；❌「未运行」时双击 `启动.bat` 后重试，
或在设置里打开自动启动）、`已安装模型`（应列出模型名如 `qwen3-vl:4b`；服务在跑但列表空 →
执行 `ollama pull qwen3-vl:4b`；列表里没有当前配置的模型 → 在设置里改选）、
`模型显存占用`（模型已加载时才出现，应显示 `已全部装进显存（3.9 GB）`；⚠️ 说明模型只有一部分
装进了显存，**识别会慢一个数量级** —— 处理办法见 `docs/03` 附录二，软件里点一下
「设置 → 本地模型 → 重新加载模型」即可修好）、
`本地模型视觉实测`（应显示 `6.8s，281 tokens（41 tok/s），读到：QINGHUA-7391`）。

> 💡 「视觉实测」是自检**现场画一张写着固定字符串 `QINGHUA-7391` 的测试图**送给本地模型，
> 看它能不能读出来。能读对，说明「模型在跑 + 真的能看图 + 速度可接受」三件事都成立，
> 是最能说明问题的单项检查。它显示 ⚠️ 时：确认用的是**视觉模型**（名字里带 vl），
> 或在设置里调大 `max_image_side`。

> ⚠️ **常见坑：识别总是把题读错、读漏。** 先看「本地模型视觉实测」这项：它都读不对，问题在
> 模型/配置；它正常但实际试卷读错，多半是**照片质量**问题——拍平、光线均匀、别用闪光灯
> （软件也会自动纠偏、提亮、去水印）。

**⑥ 云端增强连通性**：`云端增强`（默认显示 `未启用（当前：本地优先 + 云端兜底）`，
✅ 正常，**不填 Key 也完全能用**）、`云端增强连通性`（显示 `DeepSeek（云端） / deepseek-chat：正常`；
⚠️ 时检查网络、Base URL、模型名与 Key）。
云端配置细节见 **`docs/05-模型与云端接口配置教程.md`**，本文不重复。

**⑦ 导出能力**：`PDF 导出（浏览器打印）`（找到 Edge/Chrome 最好；⚠️ 未找到也**不影响使用**，
会自动改用内置渲染器生成图片版 PDF，体积略大）、`Word 导出`（`内置 .docx 生成器（无需 Office）`，
恒为 ✅）、`归档目录`（应显示 `...\data\归档`；❌ 时检查数据目录写权限）。
导出共支持 5 种格式 `txt` / `md` / `html` / `docx`（Word）/ `pdf`，
另有三种专用导出：错题本、知识点薄弱清单、错题汇总。

（结论行与总条数在报告末尾：`结论：18 项检查，失败 0 项，警告 0 项`。条数会随本机情况浮动：
模型**当前驻留**时会多一项「模型显存占用」，启用云端增强会多一项「云端增强连通性」，
不加 `--no-model` 跑模型实测会多一项「本地模型视觉实测」，所以实际是 **17~20 项**。）

**结论行的三种情况**：`一切正常，可以开始使用了 🎉` 表示全绿，直接用；
`核心功能可用（有警告项，按建议处理体验更好）` 表示能用、按建议优化；
`存在失败项，请按上面的建议处理后重试` 表示必须处理，处理不了看 `docs/03-常见问题排查.md`。

## 6. 五分钟体验：跑通一遍完整流程

**第 1 步：生成 6 张示例习题图。** 双击 **`生成示例习题图.bat`**，等黑窗口滚完，最后显示
「示例图片已生成到 samples 目录，启动软件后「导入文件夹」选择它即可」（macOS 手动执行
`python3 tools/make_samples.py`）。产物在 `samples\` 下：

| 文件名 | 内容 | 题数 | 期望状态 |
| --- | --- | --- | --- |
| `s1_math_choice.jpg` | 高中数学·函数与导数（选择题） | 3 | 正确 / 错题 / 未做 |
| `s2_math_fill.jpg` | 大学微积分（填空题） | 3 | 正确 / 正确 / 未做 |
| `s3_math_solution.jpg` | 大学线性代数（解答题） | 1 | 错题 |
| `s4_english.jpg` | 高中英语（选择+填空） | 3 | 错题 / 正确 / 正确 |
| `s5_physics.jpg` | 高中物理·牛顿第二定律（计算题） | 1 | 错题 |
| `s6_math_tilted_blur.jpg` | 与 s1 同内容，但**旋转 7° + 轻微模糊 + 偏暗 + 水印** | 3 | 正确 / 错题 / 未做 |

同时生成 `samples\ground_truth.json`（每题的标准状态），用于核对识别准不准。

> ⚠️ **常见坑：以为示例图是照片。** 它们是**画**出来的仿真卷面：A4 尺寸（1240×1754，约 150dpi），
> 带手写对勾/叉号/红笔批注。其中 `s6` 是**故意做坏**的那张，用来测试软件的自动纠偏、提亮、去水印。
> 所以如果 6 张里只有 s6 效果差一点，属正常。

**第 2 步：启动软件。** 双击 **`启动.bat`**，等界面出现，确认状态栏显示本地模型服务已就绪。

**第 3 步：导入文件夹。** 点工具栏最左边的 **`📂 导入文件夹`**，在目录选择窗口里选到软件目录下的
**`samples`** 文件夹，确定。**预期现象**：左侧「待识别图片」列表里出现 **6 张缩略图**，
预览可见预处理结果（自动对比度拉伸、纠偏、缩放）。

> ⚠️ **常见坑：提示「该文件夹里没有发现支持的图片」。** 说明选错目录了。支持 jpg / jpeg / png /
> bmp / gif / tif / tiff / webp。如果 `samples` 是空的，说明第 1 步没跑成功，重跑一遍。

**第 4 步：开始识别。** 点工具栏上的 **`▶ 开始识别`**。**预期现象**：右下角出现进度提示，
`运行日志` 标签页开始滚动；一张图约 **6~8 秒**（RTX 3070 8G 实测），**6 张图整体一两分钟**
（含自动分析和归档）；界面不会卡死——识别在后台线程跑，随时可点 `■ 停止` 中断。

**预期结果（也就是成功的判断标准）**：能看到 **6 张图 / 14 道题 / 5 道错题 / 统计图表有数据 /
导出的 Word 能打开**，说明安装部署全部成功，可以开始导入自己的真实作业了。
错题会自动触发分析报告（配置项 `run.auto_analyze`）。分布：数学 8 道、英语 3 道、物理 1 道
（`s6` 与 `s1` 内容重复，但会作为独立题目各自入库）。

> ⚠️ **常见坑：题目数和上面不一致。** 小模型识别有波动，14 道是**本机实测**的典型值，你跑出
> 13 或 15 都算正常。单张图最多切分 8 道题（配置项 `run.max_questions_per_image`，默认 8），
> 超过会被截断——一页题特别多时，建议先按题号裁图再导入。

**第 5 步：看识别结果。** 在左侧「待识别图片」里点一张图，右侧「识别结果」区列出这张图的题目，
列为：题号 / 题型 / 状态 / 置信度（0~1，越高越可信）。此区三个按钮：**`载入编辑器`** 可手工改题干、
答案、知识点；**`本地重识别`** 强制用本机模型重识别这张图；**`云端重识别`** 强制用云端重识别
（没配 Key 会提示）。切到「识别与归档」标签页，还能看大图预览、上一张/下一张、载入预处理。

**第 6 步：看错题分析。** 点顶部标签页 **`错题分析`**，或点工具栏 **`🧠 生成错题分析`** 批量生成。
每道错题有一份报告，包含：原题复述（题干/选项/你的作答）、正确答案、错因分析
（概念不清 / 计算失误 / 审题偏差 …）、知识点标签、变式练习（云端模式下更丰富）。

**第 7 步：看统计看板。** 点顶部标签页 **`统计看板`**，能看到 6 张卡片 + 4 张图表：

| 卡片 | 预期值 | 图表 | 含义 |
| --- | --- | --- | --- |
| 图片总数 | 6 | 学科分布 | 数学 / 英语 / 物理 各占多少 |
| 题目总数 | 14 | 题型分布 | 选择题 / 填空题 / 解答题 / 计算题 各占多少 |
| 错题数（红色） | 5 | 薄弱知识点 | 出错最多的知识点排序 |
| 正确题（绿色） | 6 | 错因分布 | 各类错因各占多少 |
| 未做题 | 3 | — | — |
| 错题分析报告 | 错题自动生成 | — | — |

**第 8 步：导出。** 点工具栏 **`⬇ 导出 ▾`**，菜单有 5 项：**导出选中题目…**（左侧「题库」里勾选的
题目，Word `.docx`，可另存其它格式）、**导出全部错题（个人错题本）…**（所有错题，Word）、
**导出知识点薄弱清单…**（Markdown `.md`）、**导出错题汇总…**（Markdown）、
**导出全部题目…**（题库全部，Word）。可选格式：`txt` / `md` / `html` / `docx` / `pdf`。
Word 导出是**内置实现**（用标准库直接组装 `.docx`），**不需要装 Office 或 WPS**。

**第 9 步（可选）：归档。** 点 **`🗂 归档选中`**，软件按「学科 / 年级 / 题型 / 状态」自动建目录并写
文件。在「更多 ▾ → 打开归档目录」里能看到结果，例如
`data\归档\数学\高中\选择题\错题\Q20260917-0002_错题.jpg`，同名前缀还有 `.md`（文字稿，
记事本就能打开）和 `_prep.jpg`（**预处理后**的图，已纠偏/提亮/去水印）。
目录层级由「设置 → 归档 → 目录模板」决定，默认 `{subject}/{grade}/{qtype}/{status}`。

## 7.（可选）配置云端增强

如果你希望识别更准（尤其照片模糊、字迹潦草）、错题分析更深、变式练习更强，可以配置云端增强：
「设置 → 云端模型」里填一个 OpenAI 兼容接口的 **Base URL / 模型名 / API Key**，
再勾选「启用云端增强」。DeepSeek、通义千问、智谱、Kimi、自建 OneAPI 等都支持；
软件预置了两套档案，也可「+ 新增」多套随时切换。

> 详细步骤（怎么申请 Key、怎么填、怎么测试连接、怎么控制隐私）见
> **`docs/05-模型与云端接口配置教程.md`**，本文不重复。

三点提醒：① **不配也完全能用**——默认「本地优先 + 云端兜底」模式下没填 Key 就自动全走本地，不报错；
② **隐私可控**——「设置 → 隐私与存储」里关掉「允许把图片传给云端模型」后，
云端**只收到本地识别出的文字**；③ **Key 也可以放环境变量**——配置文件里留空时，会读取
`EXER_CLOUD_API_KEY`、`DEEPSEEK_API_KEY`、`OPENAI_API_KEY` 三个环境变量中的任意一个。

## 8. 打包、迁移与卸载

**迁移到另一台电脑：把整个 `exercise-archive` 文件夹拷过去就行。** 你的全部数据都在 `data\` 里
（题库数据库、导入的原图、预处理图、缩略图、归档文件、日志、加密密钥、配置文件）。
新电脑上只需做两件事：① 装好 Python（第 2 章）；② 装好 Ollama 并 `ollama pull qwen3-vl:4b`
（第 4 章）。然后把文件夹放到**有写权限的英文路径**下，双击 `启动.bat`。

> ⚠️ **常见坑：新电脑上打开发现题库是空的。** 检查 `data\` 是否完整拷过来了。
> **千万不要只拷 `exerarchive\`**——那只是代码，题库全在 `data\` 里。

> ⚠️ **常见坑：把 `data\master.key` 弄丢了。** 它是本机的加密密钥，**没有它，加密存进数据库的
> 题干、作答、报告就再也解不出来**（表现是题库里题目全是乱码或空）。拷贝时务必连它一起拷，
> 备份时也别只备份 `archive.db`。

**日常备份**（都在「更多 ▾」菜单里）：**备份数据（打包 zip）** → `data\backup\backup_年月日_时分秒.zip`；
**导出全部数据 (JSON)** → `data\backup\export_年月日_时分秒.json`；**从备份恢复…** 用备份包覆盖当前
数据库与图片（会二次确认）。注意 `export_*.json` 是**明文**、`archive.db` 是**加密**的，各有用途，
建议都定期做一份。

**卸载 = 三件事，没有残留：**

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| ① 删软件 | 直接删除 `exercise-archive` 整个文件夹 | 题库、图片、归档、日志**一起消失**，这就是"彻底清除" |
| ② 删 Python | Windows：设置 → 应用 → 找到 Python → 卸载；macOS：删 `/Applications/Python 3.x` | 还用它干别的事就别删 |
| ③ 删模型 | 卸载 Ollama，再删模型目录（如 `~\.ollama\models` 或本机的 `C:\deepseek\ollama-models`） | 模型约 3 GB，想腾空间就删 |

> ⚠️ **删之前先备份！** 第 ① 步不可逆，`data\` 一删题库就没了。建议先「更多 ▾ → 备份数据
> （打包 zip）」，把 zip 拷到别处再动手。

**七个 `.bat` 文件速查**

| 文件 | 干什么 | 什么时候用 |
| --- | --- | --- |

| `生成示例习题图.bat` | 生成 6 张示例图 | 第一次体验、演示给别人看 |
| `运行全部测试.bat` | 跑 125 项单元测试 | 想知道程序本身有没有问题 |
| `一键验收.bat` | 7 步全自动：自检 + 单元测试 + 导出验证 + 云端通道 + 全流程 + 本地后端 + 界面截图（**不需要显卡**） | 交付验收、改完代码回归 |

**命令行也能用（可选）**

```bat
python -m exerarchive                 :: 打开图形界面（等同双击 启动.bat）
python -m exerarchive --selfcheck     :: 只做环境自检，不开窗口
python -m exerarchive --version       :: 打印版本号
python -m exerarchive --import DIR    :: 不开窗口，批量识别一个文件夹
python -m exerarchive --import DIR --force local   :: 强制只用本地引擎
python -m exerarchive --import DIR --force cloud   :: 强制只用云端引擎
```

```bash
python3 -m exerarchive
python3 -m exerarchive --selfcheck
python3 -m exerarchive --version
python3 -m exerarchive --import ./我的作业
python3 -m exerarchive --import ./我的作业 --force local
```

> ⚠️ **常见坑：命令行提示 `No module named exerarchive`。** 说明当前目录不对，
> 必须先 `cd` 到 `exercise-archive` 目录里再执行——`python -m exerarchive` 需要能在当前目录
> 找到 `exerarchive` 这个包。
