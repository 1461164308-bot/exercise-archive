AI 错题本

把手机拍的错题照片，自动变成可复习、可打印、能按知识点查找的错题本。
识别题干与手写作答 → 判定对错 → 自动分类归档 → 逐题生成错题分析 → 一键导出 Word / PDF。

下载便携版Windows 10/11 · 解压即用 查看源码GitHub 仓库

它解决什么问题

错题本最麻烦的从来不是整理，而是「抄」——抄题干、抄自己的错答、抄解析。这个工具把这一步交给模型，你只负责拍照。

1

拍照导入

支持 JPG / PNG，可一次选多张。自动做倾斜纠偏、提亮、对比度拉伸，模糊和拍歪的照片也能识别。

2

识别与判对错

读题干、读你的手写作答，判定「正确 / 错题 / 未做」，并自动归类学科、题型、知识点与年级。

3

归档与复盘

按学科和知识点自动落到归档目录；逐题生成错因分析；统计薄弱点；一键导出 Word / PDF 打印。

技术上的几个取舍

纯 Python 标准库，零第三方依赖

  • GUI 用 tkinter，图像走 GDI+，数据库用 sqlite3，加密用自实现的 ChaCha20/HMAC
  • Word 导出是手写 OOXML，不需要装 Office
  • 公式排版自己实现（分式、根号、上下标、矩阵），不依赖 MathJax

模型可以本地，也可以云端

  • 本地：接 Ollama 的视觉模型，完全离线，数据不出机器
  • 云端：任何 OpenAI 兼容接口（通义千问 / DeepSeek / GLM / 自建网关）
  • 两种模式都支持，可设「本地优先 + 云端兜底」，一个失败自动切另一个
  • 题库内容本地加密存储，密钥不出本机

快速开始

  1. 下载：到 Releases 下载 exercise-archive-portable-v1.2.0.zip（约 19 MB，带 portable 的那个）。 另一个 source 包是纯源码，需要目标电脑已装 Python。
  2. 解压：解压到不含中文和空格的路径，例如 D:\AI错题本。 不要放 C:\Program Files 下——那里没有写权限，题库会存不下来。
  3. 启动：双击 启动.bat。窗口出现即成功，此时先别急着识别。
  4. 配好模型：右上角「设置」→「云端模型」，填 Base URL / 模型名 / API Key， 并勾选「该模型支持图片」，测试连接后保存。 不勾「支持图片」是最常见的坑——云端收不到图片，会识别出 0 道题。
⚠️ 便携包自带 Python 运行时，但不含 AI 模型。
模型动辄几 GB，该用哪个取决于你的电脑和预算，所以必须由你选一条：
① 云端模型（推荐，约 5 分钟）——申请一个 API Key，阿里通义千问有免费额度，没有独立显卡也能用；
② 本地模型——装 Ollama 并 ollama pull qwen3-vl:4b（约 3 GB，需 4~6 GB 显存），完全离线。
没配好模型时，软件首页会给出醒目提示并一键跳到设置窗口。
