# v1.2.0 界面与操作指南

界面使用柔和玻璃视觉：雾白面板、浅蓝紫配色、圆角、细高光与柔影。
基于原有 Tkinter 和标准库绘制，不需要安装新依赖。
卡片为程序内合成的玻璃质感，不依赖 Windows 的实时背景模糊。

## 最常用的三步

1. 左侧「导入整理」→「导入图片」或「导入文件夹」。也可以按 Ctrl+O。
2. 点击「开始识别」。导入后显示图片队列，识别有结果后显示结果编辑区。
3. 到「我的题库」选择题目，直接阅读排版后的题干、作答、参考答案和知识点。需要纠正识别结果时点击「修改识别内容」，编辑后点击「保存修改」。

默认阅读模式会渲染数学公式；编辑模式保留原始公式文本，便于修改。点击「查看排版预览」可预览当前草稿；只有「保存修改」或 Ctrl+S 才会保存。切换到另一道题会回到阅读模式。

题库默认把空间留给题目内容；「更多」→「显示 / 收起原图对照」可以并排看原图。
「错题分析」页优先显示识别题干与分析正文：宽窗口默认并排显示原图，窄窗口默认收起原图，点击「查看原图」后也采用并排布局。
切换题目时图片同步切换；点击「放大查看」或双击预览，用系统图片查看器缩放阅读。
「收起原图 / 查看原图」切换图片区。原图缺失时尝试预处理图，图片都不可用时显示提示。
分析页上方的「识别题干与选项」直接显示识别结果，可复制、滚动查看，也可拖动分隔线调整区域高度。
这部分不依赖分析报告是否已生成；在题库中修改题干并保存后会同步更新。
「展开更多信息」包含学科、学段、题型、选项、解题步骤和标签。
内容区可以滚动，底部保存按钮保持可见。Ctrl+S 保存当前题。

## 主导航

| 入口 | 用途 |
| --- | --- |
| 导入整理 | 导入图片，预览，开始识别，核对识别结果 |
| 我的题库 | 中文状态、学科与知识点筛选，查看及修改题目 |
| 错题分析 | 选题后查看报告，生成或更新分析，进行变式练习 |
| 学习概览 | 图片、题目、错题、报告数量及薄弱知识点 |
| 搜索题目 | 搜题干、答案、知识点和报告；Ctrl+F 进入 |
| 图片优化 | 在图片队列中点「优化图片」载入后裁剪、纠偏、提亮 |
| 归档目录 | 浏览自动归档的目录结构 |
| 运行日志 | 查看任务和诊断记录 |

顶部「导出」提供选中题、个人错题本、知识点薄弱清单、汇总及全部题目导出。错题分析页隐藏全局工具栏，为报告留出空间；导出和其它全局操作可切回题库使用。
「更多」集中环境自检、备份恢复、数据目录、JSON 导出及低频维护操作。
题库底部「题目操作」中可归档、删除选中题目。

## 动效与键盘

- 按钮悬停渐变约 140 ms；导航标题过渡约 150 ms。
- 后台任务有活动进度条；收到明确进度时平滑更新。
- 识别期间标题下方和状态栏显示当前图片、批次位置、处理阶段与累计用时；队列中当前图片显示「识别中…」。
- 图片优化的「保存处理结果」固定在工具区底部，滚动工具时仍可见。
- 运行日志会写入日志文件，重新打开软件后显示近期记录，也可点击「复制全部日志」。
- 设置 → 界面与公式 →「启用轻量动效」可关闭动效，保存即生效。
- Tab 切换焦点；Enter / 空格触发导航与按钮；F5 刷新。
- 预览按窗口尺寸缩放并居中；编辑器框选会换算回原图坐标。

### v1.1.2 自动纠偏修复

检测角度描述已有的倾斜，纠正时会向相反方向旋转，修复了旧版继续沿倾斜方向旋转的问题。
此修复同时用于「自动检测倾斜并纠正」和一键自动优化、识别流水线的自动预处理。
此前已经纠偏错误的图片，在「图片优化」中先点「恢复原图」，再自动纠偏并保存处理结果；
如需更新识别文字，再重新识别该图。程序不会自动覆盖已有题库或预处理图片。

## 开发与验证

`tests/test_ui_layout.py` 验证小窗口布局、导航、中文状态保存、空态、关闭动效及居中裁剪坐标。
