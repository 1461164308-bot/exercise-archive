> **v1.2.0 · 学生体验改进**：柔和玻璃界面、左侧任务导航，题目默认以可阅读的公式预览展示。
> 错题分析页优先留足正文空间，宽窗口并排对照原图，窄窗口按需展开；自动纠偏方向修复保留。
> 从「导入整理」开始；「我的题库」中核对题干和答案，需要修改时点击「修改识别内容」；
> 在「错题分析」「学习概览」里复习。设置 → 界面与公式可关闭轻量动效。
> 新版操作入口见 [`docs/06-v1.1界面指南.md`](docs/06-v1.1界面指南.md)。

> 拍张照 → 自动识别 → 自动分类归档 → 错题自动生成分析报告。**本地小模型离线跑，复杂题自动交给云端强力模型兜底**；零第三方依赖、无付费项目、无广告、无会员限制。

## 1. 它解决什么问题

整理错题这件事，痛点从来不是「不想整理」，而是**太费时间**：抄题干、抄错解、找知识点、想变式题。
这个工具把整条链路都自动化了：

| 你的动作 | 软件做的事 |
| --- | --- |
| 手机拍一张（或整本练习册几十张）照片，拖进软件 | 自动纠偏、提亮、去水印、锐化，评估清晰度 |
| 什么都不用做 | 本地视觉模型读出题干、选项、你的手写作答、老师批注；判定**错题/正确/未做**；分类学科、细分学科、学段、题型、知识点 |
| 点一下「生成错题分析」 | 每道错题独立生成报告：**错题还原 → 错误原因 → 对应知识点 → 标准解题步骤 → 避错技巧 → 举一反三变式题**；报告里的数学按**教科书样式**排版（真正的上下标、上下分数、根号、积分上下限、**求和/连乘的上下限排在 Σ/∏ 正上正下方**、矩阵行列式），不是 `e^(2πik/6)` 这种纯文本 |
| 想复习了 | **按知识点分类**：识别出的「复数」「导数」等知识点既能一键筛选同类题（左栏「题库」→「知识点」，就在「学科」旁边），也能让归档目录按知识点分层（模板加 `{knowledge}`）；全局搜索（题干/作答/答案/知识点/报告内容都能搜）、统计看板（学科占比、题型分布、薄弱知识点、错误原因分布） |
| 想打印或发给老师 | 一键导出 Word / PDF / TXT / Markdown / HTML，或一键生成「个人错题本」「知识点薄弱清单」「错题汇总」 |

**混合运行**是核心设计：常规清晰习题用本机 4B 视觉模型离线识别（约 6~8 秒/页，不联网、不上传）；
遇到模糊、反光、字迹潦草、置信度低、识别失败的题，自动切云端强力模型复核 —— 也可以一键切成**纯本地**模式，全程不联网。

## 2. 快速开始（三步）

```bat
:: ① 部署本地视觉模型（一次就好，约 3.3GB）
ollama pull qwen3-vl:4b

:: ② 环境自检（检查 Python / 模型 / 字体 / 显卡占用 / 导出能力，有 ✅❌ 一眼看懂）
双击  环境自检.bat

:: ③ 启动软件
双击  启动.bat          :: 无控制台窗口
双击  启动-控制台.bat    :: 带控制台，排错时用

:: ④（可选）在桌面放个带图标的快捷方式，以后双击桌面图标就能开
双击  创建桌面快捷方式.bat        :: 生成 assets\app.ico 并创建桌面快捷方式
```

> 桌面快捷方式名叫 **「AI 错题本」**，图标是程序自己画的（深蓝圆角底板 + 白「题」字，
> 16~256px 七种尺寸都清晰）。桌面被 OneDrive 重定向（常见于中文 Windows）也能正确落到真实桌面上。

想先看看效果？双击 **`生成示例习题图.bat`** 生成 6 张模拟试卷照片（含手写对勾/叉号/空白/倾斜模糊水印版），
再在软件里「导入文件夹」选 `samples/` 目录，点「开始识别」即可。

**想测「认得全不全」？** `samples/大学数学/` 里另有一套**大学数学完备性样张**：9 张卷面、31 道题，
只考大学数学（极限与连续 / 导数与微分 / 积分 / 数项级数 / 行列式与矩阵 / 特征值与线性方程组 /
条件概率与贝叶斯 / 常微分方程），**每题都带手写解题过程**，覆盖 正确/错误/空白 三种状态与 6 类典型错误，
还含一张倾斜模糊压暗带水印的退化卷。逐题标准答案（题干、学生作答、正确答案、错误类型、知识点）
在 `samples/大学数学/questions.json`，页级标准答案在同目录 `ground_truth.json`：

```bat
:: 重新生成（不需要显卡）
python tools\make_univ_samples.py

:: 跑识别并和标准答案对分（需要显卡空闲；也可以直接在软件里「导入文件夹」选这个目录）
python tools\verify_recognition.py --dir samples\大学数学
```

本机基线：**31/31 题、31/31 状态全对，9 页共 68.7 秒**（`qwen3-vl:4b`，RTX 3070）。

想确认这套东西真的能跑？双击 **`一键验收.bat`**，七步全自动、全程不需要显卡：
环境自检 → 156 项单元测试 → 导出格式验证 → 云端通道验证（本地假 OpenAI 服务，真实 HTTP 往返）→
**全流程验证**（CLI + 界面走完 导入→识别→归档→错题分析→搜索→导出→备份，71 项断言）→
**本地后端验证**（Ollama 协议细节 / LM Studio 路线 / 纯本地绝不出网，35 项断言）→
界面冒烟并逐页截图。产物与结论放在 `verify/` 与 [`verify/验收报告.md`](verify/验收报告.md)。
要连真实识别一起验，再跑 `python tools\verify_recognition.py`（需要显卡空闲）。

## 3. 本机实测结果（真实运行，非估算）

在 RTX 3070 8G + `qwen3-vl:4b`（Q4_K_M）上，用 `samples/` 里 6 张模拟试卷照片跑完整流水线
（下表为 2026-09-18 接管复核时复跑的一次，模型已完整装进显存）：

| 样张 | 内容 | 识别题数 | 对/错/空白状态 | 用时 |
| --- | --- | --- | --- | --- |
| s1 | 高中数学选择题（含 ✓、✗、空白各一题） | 3/3 ✅ | 3/3 ✅ | 7.3s |
| s2 | 大学微积分填空题（∫、d/dx，含空白题） | 3/3 ✅ | 3/3 ✅ | 6.7s |
| s3 | 线性代数解答题（学生符号写错，老师批注） | 1/1 ✅ | 1/1 ✅ | 6.4s |
| s4 | 高中英语（时态/非谓语，含红叉） | 3/3 ✅ | 3/3 ✅ | 7.7s |
| s5 | 高中物理计算题（牛顿第二定律，单位漏写） | 1/1 ✅ | 1/1 ✅ | 6.6s |
| s6 | **上图的倾斜 7°+模糊+压暗+带水印版本** | 3/3 ✅ | 3/3 ✅ | 8.5s |

**合计：6 张图 43.2s（74~80 tok/s），题数准确率 14/14，对错状态准确率 14/14，学科/细分学科全部正确。**
其中 s6 由软件自动检出并纠正 7.1° 倾斜、自动提亮后完成识别（复现命令：`python tools/verify_recognition.py`）。

> ⚠️ **同一份代码，速度可能差 15 倍 —— 这是踩过的最大的坑。**
> 若模型是在「显存被占满」时加载的，Ollama 只把 11% 放进显存，之后**不会**因为显存变空而重新规划：
> 实测同样是这 6 张图，慢档要 **481.9s（6.6 tok/s）**，让模型重新加载后是 **43.2s（74~80 tok/s）**。
> 软件会主动告诉你：自检的「模型显存占用」项、识别日志里的 `识别偏慢（6.6 tok/s）：…`、
> 「刷新模型列表」后的结论行；修法就是点一下 **设置 → 本地模型 → 重新加载模型**
>（命令行等价操作与原理见 [`docs/03-常见问题排查.md`](docs/03-常见问题排查.md) 附录二）。

> 诚实说明：另一次运行里 s4 第 3 题的手写 `getting` 没被读出（判为未做，状态 13/14），
> 单独复测该张立刻读出并 3/3 —— 手写体识别存在正常波动，所以**识别结果建议人工核一眼**
>（界面上每个字段都能改，改完点「保存修改」即可）。

单元测试：`python -m unittest discover -s tests -t .` → **156 项全部通过**（含 RFC 8439 加密官方向量、
纯 Python PNG/BMP 编解码无损往返、倾斜检测 ±0.1°、加密全文检索、docx/PDF 文件结构校验、界面取图与归档模板逻辑）。

云端通道：`python tools\verify_cloud.py` → **全部通过**。这个脚本在本机起一个假的 OpenAI 兼容服务
（`http.server`），用真实 HTTP 往返验证：Base URL 三种写法、Bearer 认证、图片按 `data:image/jpeg;base64`
放在 `content[]`、`response_format` 及「服务端 400 时自动去掉重试」、`usage` token 解析、
纯文本模型/隐私开关下**一张图都不发**、服务端 500 不炸、`cloud_first` 端到端识别、
云端深度分析报告，以及「本地服务不可用 → 自动转云端」的兜底链路。

全流程闭环：`python tools\verify_workflow.py` → **71/71 项通过**。同样不需要显卡——
把假云端当引擎，把「数据在系统里怎么流动」整条链路断言一遍：
命令行导入 2 张图 → 6 道题入库（题干能从**加密库**解出）→ 错题标记与报告 → 归档目录

最后还有**异常与降级**：云端 500 不崩、返回空题目不写脏数据、云端与本地都挂时回退到规则版报告。

本地后端：`python tools\verify_local_backends.py` → **35/35 项通过**。用假 Ollama 与假 OpenAI
服务把三条本地路线各验一遍：Ollama 的裸 base64 图片 / `options` / `format` / `think` 字段、
「答案落在 `message.thinking` 而 `content` 为空」的回退、模型先回非 JSON 时自动追问重试；
LM Studio 与 `local.kind=openai_compatible` 走 `/v1/chat/completions` 的完整流水线；
以及**纯本地模式下云端收到 0 个请求**（真实 HTTP 计数）与 hybrid 的自动兜底。

## 6. 技术说明（给想改代码的人）

- **运行环境**：Python 3.8+（实测 3.12），Windows 10/11 优先；macOS 亦可运行（图像解码自动改用 `sips` + 纯 Python 解码器）。
- **零第三方依赖**：图像处理用 Windows 自带 GDI/GDI+（ctypes），PNG/BMP 有纯 Python 编解码器；
  加密自己按 RFC 8439 实现 ChaCha20 + HMAC；`.docx` 用标准库 `zipfile` 手写 OOXML；
  PDF 优先调系统浏览器打印，找不到浏览器就用内置渲染器（GDI 渲染中文 → zlib 无损嵌入）。
  装了 Pillow 会自动优先使用，但**不装也完全不影响功能**。
- **隐私**：正文在数据库里加密存放（密钥为本机 `data/master.key`，拷走 db 也读不出内容）；
  检索用 HMAC n-gram 指纹实现「密文可搜」；云端只在你开启时接收数据，可限制为只发文字不发图片。
- **改提示词**：识别字段、状态判定口径、报告深度都在 `exerarchive/prompts.py`，改完全程生效
  （提示词里明确要求模型把数学写成标准 LaTeX，例如 `$x^{n-1}$`、`$\frac{a}{b}$`、`$\begin{pmatrix}…\end{pmatrix}$`）。
- **公式排版是自己实现的**：`exerarchive/mathdraw.py` 用 ctypes 调 GDI，把 LaTeX 排成位图
  （分式上下两层 + 分数线、根号的 √ 形与横杠、上下标缩小并偏移基线、
  **Σ/∏/lim 的上下限居中排在正上/正下方**（`\int` 按中文课本习惯保留右侧上下限）、
  矩阵按列宽对齐 + 放大括号），
  再嵌进 `tk.Text`；`mathfmt.py` 负责「哪些片段是公式」以及 TXT/Markdown 的可读回退写法。
  清晰度靠 **3 倍超采样后缩回**（每像素 9 个样本），大小可在「设置 → 界面与公式」里调（默认行高的 1.15 倍）。
  想看渲染效果：`python -m exerarchive.mathdraw verify/math-preview.png`；
  真实报告公式对照图见 `verify/math-sum-pi-real-data.png`。
- **命令行也能用**：`python -m exerarchive --selfcheck`、`python tools/import_cli.py 照片目录`、
  `python tools/modelprobe.py --vision`、`python tools/verify_recognition.py`。
